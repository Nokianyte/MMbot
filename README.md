# MMbot

КОНЦЕПТ:

Текстовая игра - выживалка с взаимодействием с другими игроками посредством голосовых каналов.

Интерфейс через написания команд боту

Карта построена по условным клеткам. Игроки на одной клетке разделяют один голосовой канал. Бот сам перемещает игроков между каналами, создаёт новые, удаляет ненужные.



Проект достаточно старый, поэтому многое не оптимизировано

Выбрал делать дискорд бота из-за "голосовых каналов", которые позволят устанавливать динамичное живое взаимодействие между игроками


В игре присутствует тактовая система, которая на каждом такте будет запускать функции, проверяющие статусы игроков и тому подобное
Период тактов - примерно 2 секунды. Ожидаются осложнения в связи с задержкой, вызванной активном взаимодействием с интерфейсом дискорда


Список дел:


Игрок:
    Команды (30%)
    Статы (30%)
    Характеристики (не начато)

Карта:
    Характеристика комнаты (не начато)
    Местоположение (70%)
    Генерация (не начато)
    Лут (не начато)
    Следы (не начато) - опциаонально

Предметы:
    Список предметов (100%)
    Функционал (не начато)
    Крафт (не начато)



Сущности: - Под БОЛЬШИМ вопросм
    Условия появления
    Характеристики
    Поведения
    Сделать так, что когда игрок умирал, он мог стать сущностью

События: - не
